# expense_tracker# Python Expense Tracker

A beginner Python expense tracker that allows users to set a budget, record multiple expenses, calculate total spending, and remove expenses when spending exceeds the budget.

## Features

* Set a spending budget
* Add multiple expenses
* Store expenses using Python dictionaries
* Calculate total expenses
* Compare spending with the budget
* Display expenses with numbered options
* Remove a selected expense
* Recalculate the total after removing an expense
* Continue checking the budget after an expense is removed

## Concepts Practiced

* Variables
* User input
* Lists
* Dictionaries
* `for` loops
* `while` loops
* `if/else` statements
* `enumerate()`
* `try/except`
* `break`
* Dictionary access
* `append()` and `pop()`

## How to Run

Make sure Python is installed, then run:

```bash
python expense_tracker.py
```

Follow the prompts in the terminal to enter your budget and expenses.
